# متجر إلكتروني — متجر وسيط (Dropshipping style)

تطبيق متجر إلكتروني كامل باللغة العربية (RTL) يتيح لك:
- **استيراد منتوجات من متاجر أخرى** بمجرد لصق رابط المنتوج (السعر الأصلي يُحفظ داخلياً فقط).
- **تعديل سعر البيع** قبل النشر لإضافة نسبة الربح.
- **الإضافة اليدوية** لمنتوجاتك الخاصة.
- **لوحة تحكم** كاملة (إحصائيات، منتجات، طلبات، إعدادات).
- **سلة مشتريات + إتمام طلب** مع تخزين الطلبات.
- هيكل i18n جاهز للفرنسية والإنجليزية لاحقاً (اللغة الأساسية العربية الآن).

---

## 🚀 التشغيل السريع

### على ويندوز
اضغط مرتين على `start.bat` (أو شغّله من cmd). يقوم بـ:
1. تنصيب الحزم
2. إنشاء قاعدة البيانات
3. إدخال 6 منتوجات تجريبية
4. تشغيل السيرفر

### على لينكس / ماك
```bash
chmod +x start.sh
./start.sh
```

### أو يدوياً
```bash
npm install
node scripts/init-db.js
node scripts/seed.js
npm start
```

ثم افتح:
- **المتجر**: http://localhost:3000/
- **لوحة التحكم**: http://localhost:3000/admin/ (كلمة المرور الافتراضية: `admin123`)

> **غيّر كلمة المرور** من داخل لوحة التحكم (راجع صفحة الإعدادات) بعد أول دخول.

## 🧱 المعمارية

| الطبقة | التقنية |
|---|---|
| Backend | Node.js 20+ / Express 4 |
| قاعدة البيانات | `node:sqlite` (مدمجة في Node 22/24) — مع fallback تلقائي إلى `better-sqlite3` على الإصدارات الأقدم |
| رفع الملفات | `multer` 2.x |
| استخراج بيانات المنتوجات | `cheerio` (JSON-LD + Open Graph + heuristics) |
| القوالب | EJS (Server-side rendering) |
| اللغة | عربية (RTL) + FR/EN جاهزة |
| التخزين | قاعدة بيانات محلية `data/store.db` + صور `public/uploads/` |

## ✨ كل الميزات

### للزبون (المتجر العام)
- ✅ صفحة رئيسية بـ hero + منتجات مميزة
- ✅ صفحة كل المنتجات مع بحث وفلترة بالفئة
- ✅ صفحة منتوج تفصيلية (صورة، وصف، سعر، إضافة للسلة)
- ✅ سلة مشتريات (cookie، تدوم 30 يوم)
- ✅ إتمام طلب (اسم، هاتف، مدينة، عنوان)
- ✅ صفحة تأكيد الطلب
- ✅ تصميم متجاوب RTL كامل بالعربية
- ✅ فوتر احترافي

### للمدير (لوحة التحكم `/admin`)
- ✅ **تسجيل دخول** بكلمة مرور (cookie 14 يوم)
- ✅ **لوحة إحصائيات** مع فصل واضح:
  - **مبيعات المنتجات** (بدون شحن)
  - **الشحن المُحصّل** (منفصل)
  - **🟢 صافي ربحك المحقق** = (سعر البيع − السعر الأصلي) × الكمية المباعة
  - **ربح متوقع من المخزون** = لو بعت كل المخزون الآن
  - عدد المنتجات / المنشور / المستورد
  - إجمالي الطلبات / الجديدة
- ✅ **قائمة المنتجات** مع عرض:
  - سعر البيع / السعر الأصلي / **الربح** ونسبته
  - رابط المصدر
  - نوع المنتوج (مستورد / يدوي)
  - حالة النشر
- ✅ **إضافة يدوية** بمنتوج كامل (اسم، وصف، صور، سعرين، فئة، مخزون)
- ✅ **تعديل منتوج** (نفس الحقول)
- ✅ **حذف منتوج** (مع حذف صورته من القرص)
- ✅ **استيراد من رابط** (القلعة 🏰):
  1. الصق رابط المنتوج من أي متجر
  2. يستخرج الاسم، الوصف، الصورة، السعر تلقائياً
  3. يعرض معاينة قابلة للتعديل
  4. **يقترح سعر بيع** = السعر الأصلي × (1 + نسبة الزيادة من الإعدادات)
  5. **تعدّل كل شيء** قبل النشر (الاسم، السعر، الصورة…)
  6. تضغط "نشر" فيظهر في المتجر
- ✅ **إدارة الطلبات**:
  - عرض تفصيلي (الزبون، المنتجات، المجموع)
  - **ربح الطلب** (بدون شحن) ظاهر بوضوح
  - **تعديل رسوم الشحن لكل طلب** (مثلاً لو التوصيل أكتر أو أقل من المعتاد)
  - تغيير الحالة (جديد / مؤكد / شُحن / تم التسليم / ملغي)
  - حذف الطلب
- ✅ **الإعدادات**:
  - اسم المتجر
  - الشعار
  - العملة
  - نسبة الزيادة الافتراضية %
  - **رسوم الشحن الثابتة** (قابلة للتعديل)
  - **حد الشحن المجاني** (مثلاً: مجاني فوق 500 د.م.)
  - طريقة تغيير كلمة المرور

### API
- `POST /api/scrape` و `GET /api/scrape?url=...` — يعيد JSON ببيانات المنتوج المستخرج (مفيد للاستخدام الخارجي).

## 🔗 كيف يعمل "الاستيراد من رابط"؟

في `lib/scraper.js`، استراتيجية الاستخراج بالترتيب:

1. **JSON-LD** (`<script type="application/ld+json">` schema.org/Product) — هذا ما تستخدمه معظم المتاجر الكبرى (Amazon, AliExpress, eBay, Jumia, etc.)
2. **Open Graph + Twitter cards** — fallback شائع
3. **Microdata** (`itemprop="name|price|image"`) — بعض المتاجر القديمة
4. **Heuristics CSS** (`.price`, `.product-price`, `[data-price]`, …) — للمواقع الصغيرة

**يدعم**: جلب صور متعددة (gallery)، السعر، العملة، اسم النطاق المصدر.

**حدود معروفة**:
- بعض المواقع تحظر البوتات (403). في هذه الحالة، استعمل خاصية "الإضافة اليدوية" وانسخ المعلومات يدوياً.
- الصور المستوردة تبقى على سيرفر الموقع الأصلي. إذا أردت تخزينها محلياً، أضف خطوة download (يمكن إضافتها لاحقاً).

## 💰 كيف يُحسب الربح؟ (مهم جداً)

**الربح = سعر البيع − السعر الأصلي** (السعر الأصلي مخفي عن الزبون، محفوظ في `original_price`).

| العمود في لوحة التحكم | المعنى |
|---|---|
| مبيعات المنتجات | مجموع أسعار البيع لكل الطلبات (بدون شحن) |
| الشحن المُحصّل | مجموع رسوم الشحن (لا يدخل في الربح) |
| 🟢 صافي ربحك المحقق | مجموع (سعر البيع − السعر الأصلي) × الكمية عبر كل الطلبات |
| ربح متوقع من المخزون | مجموع (سعر البيع − السعر الأصلي) × المخزون الحالي |

**رسوم الشحن منفصلة تماماً** — تُحصّل من الزبون لتغطية تكلفة التوصيل، ولا تُحسب ضمن ربحك.

### تعديل الشحن
- **عام** (لكل المتجر): من الإعدادات → رسوم الشحن الثابتة
- **لكل طلب على حدة**: من صفحة "الطلبات" → افتح الطلب → عدّل حقل "الشحن" واضغط حفظ
- **شحن مجاني تلقائي**: ضع حداً (مثلاً 500 د.م.) في الإعدادات → "حد الشحن المجاني"

## 💡 أفكار إضافية مقترحة (للتطوير لاحقاً)

1. **تنزيل الصور محلياً** عند الاستيراد (لتفادي انكسار الروابط).
2. **تنبيهات المخزون** (إيميل/إشعار عند وصول المخزون لصفر).
3. **كوبونات خصم** للزبائن.
4. **دفع أونلاين** (Stripe / CMI / PayPal).
5. **تأكيد الطلبات عبر واتساب** (زر مباشر).
6. **تقارير PDF** للمبيعات.
7. **استيراد بالجملة** (عشرات الروابط دفعة واحدة، ملف CSV مثلاً).
8. **تعدد اللغات** (تفعيل FR/EN من الإعدادات — البنية جاهزة).

## 🛠️ تخصيصات سريعة

### تغيير منفذ التشغيل
```bash
PORT=8080 npm start
```

### تغيير كلمة مرور المدير
شغّل هذا الأمر من مجلد المشروع (يتطلب sqlite3 CLI):
```bash
sqlite3 data/store.db "UPDATE settings SET value='كلمة_جديدة' WHERE key='admin_token';"
```
أو افتح `data/store.db` بأي أداة SQLite (مثل DB Browser for SQLite).

### تغيير نسبة الزيادة الافتراضية
من لوحة التحكم → الإعدادات → "نسبة الزيادة الافتراضية عند الاستيراد (%)".

## 🐛 حل المشاكل

| المشكلة | الحل |
|---|---|
| `Cannot find module 'node:sqlite'` | استخدم Node 22.5+ أو 24. سيُحاول البرنامج تلقائياً استخدام `better-sqlite3` كبديل (لكن الأفضل تحديث Node). |
| `EADDRINUSE` (المنفذ 3000 مشغول) | شغّل `PORT=4000 npm start` |
| الصور لا تظهر | تأكد أن مجلد `public/uploads/` موجود وقابل للكتابة. |
| الاستخراج يعطي خطأ من موقع معيّن | ذلك الموقع يحظر البوتات. استعمل الإضافة اليدوية. |
